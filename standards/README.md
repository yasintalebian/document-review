# ISO/IEC 27001:2022 baseline

`iso27001_2022_baseline.example.json` contains high-level review anchors for clauses 4–10 and the four Annex A control families. It intentionally does not reproduce the copyrighted standard.

For an organization-level conformity review, copy the example to `iso27001_2022_baseline.json` and complete each requirement with the organization's licensed requirement summaries and approved Statement of Applicability references. Keep the licensed source and any confidential SoA outside the public repository.

The result is an evidence-oriented review report. It is not a certification decision or a substitute for an auditor.
